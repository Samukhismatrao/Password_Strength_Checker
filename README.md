# Password Strength Checker

## About the Project
Password Strength Checker is a simple Python-based project that checks the strength of a password.

## Features
- Checks password length.
- Checks uppercase and lowercase letters.
- Checks numbers.
- Checks special characters.
- Displays password strength as Weak, Medium, or Strong.

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python password_checker.py
```

4. Enter a password to check its strength.

## Password Strength Levels
- Weak: Score 0–2
- Medium: Score 3–4
- Strong: Score 5
